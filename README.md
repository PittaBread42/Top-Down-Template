# **Top-Down Game Template**

This is a top-down (bird's-eye view) game template. Top-down games can be a variety of different genres, so this is supposed to be everything faffy needed before the uniqueness of the game begins. 

**Included**

NIY = Not implemented yet (it's not currently used in the game)

- Player Movement
- Transitions between areas
- Opening an inventory
- Picking up items
- Moving items in an inventory (swapping, snapping)
- Dropping items
- Stacking and splitting items
- Hot-bar
- Opening chests
- Saving chest states, inventory states and player position after the game is stopped (I don't actually know how you 'stop' a game in Unity play, but it works in Unity)
- Items have an effect when dropped
- Two map scripts (I have used the manual one in my game)
- Pausing the game when the UI is open
- NPC interaction scripts
- NPC movement between waypoints
- NPC animation 
- Sound Effects - NIY
- Quest System - NIY

**Building Process**

I am building this in Unity, writing the scripts I need as I go in Visual Studio. This is my first proper Unity project, so I am using an amazing tutorial (https://m.youtube.com/watch?v=HAVp6Z8b4xA&list=PLaaFfzxy_80HtVvBnpK_IjSC8_Y9AOhuP&index=3&pp=iAQB0gcJCY8Co7VqN5tD&ra=m). And an asset pack (https://pixel-boy.itch.io/ninja-adventure-asset-pack).

**Playing**

As per usual, WASD or arrow keys to move. You can open the inventory/settings/map(/player-currently empty) with the 'i' key. Use the mouse to drag objects around the inventory or out of it. Use the 'e' key to interact with objects.
