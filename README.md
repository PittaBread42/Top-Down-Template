#Top-Down Game Tepmlate

This is a top-down (bird's-eye view) game template. Top-down games can be a variety of different genres, so this is supposed to be everything faffy needed before the uniqueness of the game begins. 

#Included

This project included player movement, moving between maps, an inventory, hotbar, dragging and dropping items and records of picked up items in the corner of the screen when items are picked up.

#Building

I am building this in Unity, writing the scripts I need as I go in Visual Studio. This is my first proper Unity project, so I am using an amazing tutorial (https://m.youtube.com/watch?v=HAVp6Z8b4xA&list=PLaaFfzxy_80HtVvBnpK_IjSC8_Y9AOhuP&index=3&pp=iAQB0gcJCY8Co7VqN5tD&ra=m). Also using a brilliant asset pack (https://pixel-boy.itch.io/ninja-adventure-asset-pack).

#Playing

As per usual, WASD or arrow keys to move. You can open the inventory/settings/map(/player-currently empty) with the 'i' key. Use the mouse to drag objects around the inventory or out of it.
